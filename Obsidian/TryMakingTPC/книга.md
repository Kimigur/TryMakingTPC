![[книга локации.png]]
при нажатие ПКМ по выбранной карте всплывает её описание, при повторном нажатие ПКМ на выбранную карту она будет "использована" и информация о локации будет перенесена на страницу с картой локации. Если карт слишком много, то справа на 1-й локации есть ползунок, тоща который вниз появятся другие карты локации![[книга монстры.png]]
при нажатие ПКМ по выбранной карте всплывает её описание, при повторном нажатие ПКМ на выбранную карту она будет "использована" и информация о локации будет перенесена на страницу с картой локации. ![[книга артефакты.png]]
При нажатие ПКМ по выбранному артефакту, появляется его описание и список монстров, на которых можно его "одеть". При нажатие ПКМ по монсту всплывут его артефакты, при повторном нажатие ПКМ на него будет "одеть" артефакт и он будет записан в карту монстра. Если артефактов слишком много, то потянув за ползунок вниз будут видны артефакты стоящие ниже по списку
