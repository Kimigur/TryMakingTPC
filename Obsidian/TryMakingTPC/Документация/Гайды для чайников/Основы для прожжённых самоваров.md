## Начало боя
В начале боя для всех [[Unit]] на доске устанавливается [[Core]] и [[Board]] после чего вызывается `reset_bonus()` который сбрасывает бонусы юнита и обходит все [[Artifact]] в инвентаре и использует для них `add_bonus()` затем вызывается `ready()` для юнитов и всех артифавктов.
!Важно, в \_init() внутри юнита, не ставим `set_base_ac(...)`, делаем это только на этапе `ready()`, почему так. А потому, что если надета браня, то нагрудник ставит свой `base_ac` и что бы \_init и ready не мешали, то `base_ac` ставится 1 раз, но если не 1 артифакт не поставил `base_ac`, то в `rady` можно установить базовое значение!
После этого ядро само прокидывает инициативу, и выстраивает очередь, на основании результатов, но юниты окружения(type == 2) всегда в конце очереди.
Если делать схемой то получается так

start_combat
1). `set_core()` `set_board()` для юнитов
2). `reset_bonus()` `add_bonus()`
3). `ready()`
4). формирование очереди 1 ход и сигнал [[event_bus#combat_started]]

Круг идёт так:
1). сигнал [[event_bus#round_changed]]
2). Дальше берём следующего юнита из очереди сбрасываем ему бонус(`reset_bonus()`), скорость, действие и смотрим
- Если юнит эта кукла-дм-а, то ждём ввод пользователя
- Если юнит авантюрист или окружение, то для него используем `execute()`
3). сигнал [[event_bus#turn_changed]] ипровиряем 
- Если в очереди есть ещё юнит, то переходим к этапу 2
- Иначе к этапу 1
(Пока условия выхода из боя нет, это потом изменится.)

### Unit
[[Unit]] это базовый класс для любого элемента на доске от банального дерева, до авантюриста война 20 уровня
Давай я тебе сразу дам шаблон а чуть ниже расскажу что да как
```gd-script
extends Unit
class_name *NAME*

func _init():
	set_unit_name("*NAME*") # Имя юнита
	set_model(preload("res://assets/3D models/OBJ/Фигуры/")) # Загрузка модели
	set_type(0)          # Тип юнита
	
	set_max_hp(20)       # Максимальное хп
	set_hp(20)           # Текущее хп (можно просто hp = max_hp или hp = 20)
	
	# Сопротивления по умолчанию 1, 
	# 0 - уязвимость(в 2 раза больше урона)
	# 1 - обычно(урон не меняется)
	# 2 - сопротивления (в 2 раза меньше урона)
	# 3 - имунитет (урона нет) 
	set_resistance_bludgeoning(1) # Дробящий
	set_resistance_piercing(1)    # Колющий
	set_resistance_slashing(1)    # Рубящий
	
	set_resistance_fire(1)        # Огонь
	set_resistance_cold(1)        # Холод
	set_resistance_lightning(1)   # Молния
	set_resistance_acid(1)        # Кислота
	set_resistance_poison(1)      # Яд
	
	set_resistance_force(1)       # Силовой урон
	set_resistance_radiant(1)     # Лучистый урон 
	set_resistance_necrotic(1)    # Некротический урон
	set_resistance_psychic(1)     # Психический урон
	
	set_ac(10)       # для ui до начала боя
	
	set_max_speed(5) # Максимальная скорость
	
	set_strength(10)     # Сила
	set_dexterity(10)    # Ловкость
	set_constitution(10) # Телосложение
	set_wisdom(10)       # Мудрость
	set_intelligence(10) # Интелект
	set_charisma(10)     # Харизма
	
	# Слоты инвенторя, при необходимости можно null заменить на artifact.new()
	set_main_hand_slot(null)   # Главная рука 
	set_off_hand_slot(null)    # другая рука
	set_armor_slot(null)       # Броня
	set_helm_slot(null)        # Шлем
	set_gloves_slot(null)      # Перчатки
	set_boots_slot(null)       # Тапки
	set_accessory_1_slot(null) # Слот аксесуаров 1
	set_accessory_2_slot(null) # Слот аксесуаров 2
	set_accessory_3_slot(null) # Слот аксесуаров 3
	set_accessory_4_slot(null) # Слот аксесуаров 4
	
	# Действия, по умолчанию все кроме легиндарного 1
	set_free_actions_max(1)      # Свободное действие
	set_main_actions_max(1)      # Действие
	set_bonus_actions_max(1)     # Бонусное действие 
	set_reaction_actions_max(1)  # Реакция
	set_legendary_actions_max(0) # Легендарное действие
	
	lock_stats() # Блакируем статы что бы случайно не поменять

func ready():
	set_base_ac(10) # если броня не дала базовый кд

func execute():
	pass
```

Ну или чистый шаблон
```gd-script
extends Unit
class_name *NAME*

func _init():
	set_unit_name("*NAME*")
	set_model(preload("res://assets/3D models/OBJ/Фигуры/"))
	set_type(0)
	
	lock_stats()

func ready():
	pass

func execute():
	pass
```

Так начнём по порядку
```gd-script
func _init():
	...
```
Вызывается при создании юнита для выдачи стартовых статов и предметов при необходимости.
Что за что отвечает описано в шаблоне
`lock_stats()` блокирует изменение базовых  значений
!Важно, на этом этапе `get_core()` и `get_board()` не доступны!

```gd-script
func ready():
	pass
```
Выполняется в начале боя, в нём уже доступны `get_core()` и `get_board()` можно использовать для изменения внутренних параметров перед боем
```gd-script
func execute():
	pass
```
Выполняется в момент, когда до юнита дошел ход


### Cell
[[Cell]] — это клетка доски. Сейчас используется как заглушка, но в будущем здесь будет вода, ловушки и прочий ландшафт.

```gd-script
extends Cell
class_name *NAME*

func _init():
	set_cell_name("*NAME*") # Имя клетки
```

Чистый шаблон

```gd-script
extends Cell
class_name *NAME*

func _init():
	set_cell_name("*NAME*")
```

`set_cell_name()` — отображаемое имя, по умолчанию `"EmptyCell"`.
